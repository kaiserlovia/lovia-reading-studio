# lovia-reading-studio
Lovia 阅读主题展示工坊 · 三图画报编辑与高清 PNG 导出

## 两种展示风格

- **Lovia 经典**（`index.html`）：原本的画报，原有排列的输出保持不变；另外可以上传日间组、夜间组两组截图，并新增日夜成对、日夜对开、日夜斜切、日夜交错四种版型。
- **Day Night**（`daynight.html`）：日间、夜间截图放进同一张画报，并加入 Lovia 经典的全部功能。

页面顶部的切换按钮可以在两者之间切换，主题名称、作者、日期、留言和上传的截图会一起带过去（只保存在当前浏览器）。右侧的「繁 / 简」按钮切换界面文字。

## 原创艺术打码

两套编辑器的大预览正上方均有靛蓝色折叠卡片，默认收起且效果关闭。展开后开启总开关，选择图片并设置风格；收起面板仍保留效果，关闭总开关立即还原原图且保留参数。

- 八种实际 Canvas 算法：星砂雾影、流线密纹、银雕暗纹、琉璃折影、织影网格、霜雾玻璃、星屑刻印、灰阶网印。风格缩略图由当前原图计算生成。
- 每张日间、夜间图片独立启用、设置参数；可复制到全部图片或通过复选框选择作用对象。
- 提供强度、原图可见度、密度、纹理透明度，以及当前风格专用的高级参数。支持自动、浅色、深色、黑白灰和五色自定义配色。
- 随机纹理由种子决定，预览和导出使用同一种子。预设保存在当前浏览器；原有整套预设和两页切换也携带艺术打码设置。
- 原图对比只影响实时预览；PNG、放大图与动图仍使用已启用的效果。图像处理始终读取原图，背景、字体、边框和布局沿用原有逻辑。

算法和界面分别位于 `art-mosaic.js`、`art-mosaic.css`，不增加运行时第三方依赖。预览采用适配显示尺寸的工作图；导出按实际输出尺寸重新取原图计算（最多 4096px 长边 / 800 万像素的单图工作缓冲）。

## 构建与验证

网站仍可直接用静态服务器或 GitHub Pages 托管，无需 Node 运行时。开发校验使用 Node.js 22 或更新版本：

```sh
npm ci
npm run build
npx playwright install chromium
npm test
npm run preview
```

`build` 检查两页 JavaScript、内联脚本及本地资源引用，再复制静态站点至 `dist/`。`preview` 地址为 `http://127.0.0.1:4173`。已有 Chrome 时可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 跳过浏览器下载。

浏览器测试覆盖两页桌面和 390px 手机尺寸、折叠与键盘状态、逐图设置、配色、预设、批量范围、PNG 下载、原图还原、页面间配置传递、深色模式以及原有比例和排版控制。像素测试固定使用软件 Canvas，避免浏览器多次读回像素时切换 GPU/CPU 导致采样差异。外部字体在测试中使用本地回退；父站点的 `shared/cloud.v1.js` 不在此仓库内，隔离测试不访问云端预设服务。测试截图保存在系统临时目录的 `lovia-art-mosaic-evidence/`。
