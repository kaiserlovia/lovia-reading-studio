# lovia-reading-studio
Lovia 阅读主题展示工坊 · 三图画报编辑与高清 PNG 导出

## 两种展示风格

- **Lovia 经典**（`index.html`）：原本的画报，原有排列的输出保持不变；另外可以上传日间组、夜间组两组截图，并新增日夜成对、日夜对开、日夜斜切、日夜交错四种版型。
- **Day Night**（`daynight.html`）：日间、夜间截图放进同一张画报，并加入 Lovia 经典的全部功能。

页面顶部的切换按钮可以在两者之间切换，主题名称、作者、日期、留言和上传的截图会一起带过去（只保存在当前浏览器）。右侧的「繁 / 简」按钮切换界面文字。

## 原创艺术打码

两套编辑器的大预览正上方均有靛蓝色折叠卡片，默认收起且效果关闭。效果统一覆盖整张成品（背景、截图、边框与文字），无需选择作用图片或范围。收起面板仍保留效果，关闭开关还原未打码的完整成品并保留参数。

- 风格前新增「模糊」「摩尔纹」「水印图」，保留原有八种风格，共十一种。缩略图从完整成品实时生成。
- 水印可导入 PNG、JPG、WebP、GIF、AVIF（12 MB / 2400 万像素以内），支持透明 PNG；按完整成品平铺，可调整大小、间距、旋转、强度和透明度。
- 纹理配色精简为「自动取色」与「自选颜色」，自选模式可编辑五个色块。
- 艺术预设通过 IndexedDB 保存设置和水印原文件，刷新后仍可恢复；旧版纹理预设继续可用。原有整套预设及两页切换也携带水印文件。水印不会被云端预设压缩成不透明 JPEG。
- 每次从未打码的完整海报重新计算效果，不叠加处理旧帧。PNG、放大图和动图均在最终合成后只应用一次；原图对比只影响实时预览。

算法和界面分别位于 `art-mosaic.js`、`art-mosaic.css`，不增加运行时第三方依赖。效果按当前预览或导出画布的实际分辨率重新计算，纹理尺寸按画布比例缩放。

## 构建与验证

网站仍可直接用静态服务器或 GitHub Pages 托管，无需 Node 运行时。开发校验使用 Node.js 22 或更新版本：

```sh
npm ci
npm run build
npx playwright install chromium
npm test
npm run preview
```

`build` 检查两页 JavaScript、内联脚本及本地资源引用，再复制静态站点至 `dist/`。`preview` 地址为 `http://127.0.0.1:4173`。已有 Chrome 时可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 跳过浏览器下载。

浏览器测试覆盖两页桌面和 390px 手机尺寸、折叠与键盘状态、整图覆盖、配色、水印预设持久化、PNG 下载、原图还原、页面间配置传递、深色模式以及原有比例和排版控制。像素测试固定使用软件 Canvas，避免浏览器多次读回像素时切换 GPU/CPU 导致采样差异。外部字体在测试中使用本地回退；父站点的 `shared/cloud.v1.js` 不在此仓库内，隔离测试不访问云端预设服务。测试截图保存在系统临时目录的 `lovia-art-mosaic-evidence/`。
